# Gym Workout Tracker 🏋️‍♂️

A simple **console-based Gym Workout Tracker** built using Python.  
It helps users track exercises, sets, reps, and weight for daily workouts.

## Features
- Add workout details
- View all workouts
- See total exercises done
- Beginner-friendly menu system

## Technologies Used
- Python

## How to Run
1. Make sure Python is installed
2. Run the program using:
   python workout_tracker.py
